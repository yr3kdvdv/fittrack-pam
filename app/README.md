# FitTrack

Личный дневник тренировок: каталог упражнений по группам мышц, история
тренировочных сессий, статистика и профиль. Учебный проект курса PAM, тема T2.

Текущий этап — L4: разделяемое состояние (provider, модели `ChangeNotifier`)
и паттерн Repository на mock-данных. Форма тренировки сохраняет, изменяет и
удаляет записи; дневник, badge вкладки «Дневник», статистика и профиль
обновляются сразу. Каталог ищет и фильтрует по группе мышц. Каждый экран с
данными показывает загрузку (около 0,8 с), данные или ошибку с кнопкой
«Повторить»; кнопка «Обновить» в AppBar перезапрашивает данные.

Для демонстрации ошибки: Профиль → «Симулировать сбой сети», затем «Обновить»
на любом экране. Выключите переключатель и нажмите «Повторить».

Данные живут в памяти до перезапуска приложения: сети, сохранения на диск и
настоящей авторизации на L4 нет (backend — L5, локальное хранение — L6). Для
входа подходят любой правдоподобный e-mail и пароль не короче 6 символов.

## Запуск

Нужны Flutter 3.47+ (Dart 3.13+) и запущенный эмулятор Android или телефон
с включённой отладкой по USB. Проверено на Flutter 3.47.5, Dart 3.13.4,
Android 15 API 35. Версии в lock-файле: go_router 18.1.1, provider 6.1.5+1.

Из корня репозитория:

```sh
cd app
flutter pub get
flutter devices
flutter run
```

После изменения карты маршрутов или корня композиции в `main.dart` нужен
полный перезапуск приложения.

## Проверки

Из папки app:

```sh
dart format --output=none --set-exit-if-changed lib test
flutter analyze
flutter test
```

## Структура

- `lib/main.dart` — корень композиции: выбор mock-реализаций, MultiProvider
  с моделями над MaterialApp.router.
- `lib/router.dart` — адреса экранов, вложенные маршруты и ветки вкладок.
- `lib/models/` — модели `ChangeNotifier` (дневник, каталог, профиль) и расчёт
  статистики.
- `lib/data/` — сущности, `Result`, интерфейсы Repository, mock-реализации,
  общий `MockNetwork` (задержка и авария) и seed-данные.
- `lib/screens/` — экраны, формы и оболочка NavigationBar.
- `lib/widgets/` — переиспользуемые компоненты, в том числе `ErrorView`.
- `test/` — модели, repositories, состояния экранов, мутации, переходы,
  валидация и вёрстка.
