# FitTrack

Личный дневник тренировок: каталог упражнений по группам мышц, история
тренировочных сессий, статистика и профиль. Учебный проект курса PAM, тема T2.

Текущий этап — L3: адресная навигация go_router, четыре постоянные вкладки,
локальная валидация входа и формы тренировки, SnackBar и подтверждение выхода.
Вкладки сохраняют открытый экран и прокрутку. Для входа подходят любой
правдоподобный e-mail и пароль длиной не менее 6 символов.

Данные остаются демонстрационными: подтверждение формы не изменяет дневник.
Поиск и фильтры пока служат макетом. Общее состояние и Repository появятся
на L4, реальная авторизация и backend — на L5.

## Запуск

Нужны Flutter 3.47+ (Dart 3.13+) и запущенный эмулятор Android или телефон
с включённой отладкой по USB. Проверено на Flutter 3.47.5, Dart 3.13.4,
Android 15 API 35. Версия go_router в lock-файле — 18.1.1.

Из корня репозитория:

```sh
cd app
flutter pub get
flutter devices
flutter run
```

После изменения карты маршрутов нужен полный перезапуск приложения.

## Проверки

Из папки app:

```sh
dart format --output=none --set-exit-if-changed lib test
flutter analyze
flutter test
```

## Структура

- `lib/main.dart` — MaterialApp.router и тема.
- `lib/router.dart` — адреса экранов, вложенные маршруты и ветки вкладок.
- `lib/theme.dart` — ThemeData на основе ColorScheme.fromSeed.
- `lib/screens/` — экраны, формы и оболочка NavigationBar.
- `lib/widgets/` — переиспользуемые компоненты.
- `lib/data/` — общие модели и неизменяемые mock-данные.
- `test/` — валидаторы, переходы, формы, состояние вкладок и вёрстка.
