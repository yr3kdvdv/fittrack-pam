# FitTrack

Учебный проект по дисциплине «Программирование мобильных приложений» (PAM).
Тема T2: дневник тренировок.

## L2

Статический интерфейс Flutter Material 3: вход, каталог упражнений, детали
упражнения, дневник, форма новой или редактируемой сессии, статистика и профиль.
10 упражнений, 13 тренировок, итоги за 6 недель. Поиск, фильтры и сохранение
демонстрационные; бизнес-логика следующих лабораторных не реализована.

- [Приложение](app/) и [инструкция запуска](app/README.md).
- [Отчёт Word без титульного листа](docs/L2/PAM_L2_FitTrack.docx).
- [Объяснение кода](docs/EXPLAIN/L2.md).
- [Скриншоты Android](docs/L2/evidence/).

Для запуска нужны Flutter 3.47+ (Dart 3.13+) и Android-устройство:

```sh
cd app
flutter pub get
flutter run
```

Проверки:

```sh
dart format --output=none --set-exit-if-changed lib test
flutter analyze
flutter test
```

27.10.2026: анализ без замечаний, 36 тестов пройдены.
Устная защита является отдельным этапом.
