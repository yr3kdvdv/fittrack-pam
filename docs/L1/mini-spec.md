# Мини-спецификация проекта

## Тема

**T2. FitTrack — дневник тренировок.** Домен: здоровье и фитнес. Приложение будет
строиться на L2–L6; сейчас это план, кода приложения ещё нет.

## Целевая аудитория и проблема

Студенты, которые регулярно тренируются и хотят видеть свою динамику. Бумажную
тетрадку легко забыть или потерять в раздевалке, и история тренировок пропадает.
FitTrack хранит каталог упражнений и дневник сессий в телефоне, поэтому прогресс
всегда под рукой.

## Экраны

1. **Вход / регистрация** — один экран с двумя режимами.
2. **Каталог упражнений** — список с поиском и фильтром по группе мышц.
3. **Карточка упражнения** — описание, техника выполнения, изображение.
4. **Дневник тренировок** — список сессий в хронологическом порядке.
5. **Форма сессии** — создание и редактирование: дата, упражнения, длительность,
   заметки.
6. **Статистика прогресса** — сессии в неделю, суммарная длительность.
7. **Профиль пользователя.**

## Сущности

Поля совпадают с моделью данных темы. Типы предварительные, их сверю с backend на L5.

**Exercise** — упражнение из каталога.

| Поле | Тип | Значение |
|---|---|---|
| `id` | `String` | идентификатор |
| `name` | `String` | название |
| `muscleGroup` | `String` | группа мышц, по ней работает фильтр |
| `description` | `String` | описание и техника |
| `imageUrl` | `String` | ссылка на изображение |

**WorkoutSession** — одна тренировка в дневнике.

| Поле | Тип | Значение |
|---|---|---|
| `id` | `String` | идентификатор |
| `userId` | `String` | владелец сессии |
| `date` | `DateTime` | дата тренировки |
| `exerciseIds` | `List<String>` | выполненные упражнения (ссылки на `Exercise.id`) |
| `durationMin` | `int` | длительность в минутах |
| `notes` | `String` | заметки |

## Почему эта тема

Я сам спортсмен, поэтому для меня это приложение будет полезным не только как
учебный проект. Мне важно видеть, сколько и как регулярно я тренируюсь, а дневник в
телефоне удобнее записей, которые легко потерять. Делая FitTrack, я смогу сразу
проверять его на своих тренировках и замечать, чего в нём не хватает.
